## 1. Зачем нужны циклы

Циклы позволяют повторять действия. Без них мы не можем:
- Обходить коллекции данных
- Повторять операцию до выполнения условия
- Реализовывать большинство алгоритмов

В TypeScript есть 3 основных типа циклов: `while`, `for`, `do-while`.

---

## 2. Цикл `while`

### Синтаксис

```typescript
while (условие) {
  // тело цикла
}
```

### Как работает

1. Проверяется условие
2. Если `true` — выполняется тело цикла
3. Возвращаемся к шагу 1
4. Если `false` — выходим из цикла

### Пример

```typescript
let count = 0;
while (count < 5) {
  console.log(count);
  count++;
}
// Выведет: 0, 1, 2, 3, 4
```

### Когда использовать

- Когда **количество итераций неизвестно заранее**
- Когда условие выхода — сложное выражение
- Когда нужно ждать какого-то события

### Пример: ожидание события

```typescript
let isReady = false;
while (!isReady) {
  // Ждём, пока система не будет готова
  isReady = checkSystemStatus();
  if (!isReady) {
    sleep(1000);  // Пауза 1 секунда
  }
}
```

## 3. Цикл `for`

### Синтаксис

```typescript
for (инициализация; условие; обновление) {
  // тело цикла
}
```

### Как работает

1. Выполняется **инициализация** (один раз)
2. Проверяется **условие**
3. Если `true` — выполняется тело цикла
4. Выполняется **обновление**
5. Возвращаемся к шагу 2
6. Если `false` — выходим из цикла

### Пример

```typescript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
// Выведет: 0, 1, 2, 3, 4
```

### Когда использовать

- Когда **количество итераций известно заранее**
- Когда обходишь массив или диапазон чисел
- Когда есть счётчик

### Пример: обход массива

```typescript
const numbers = [10, 20, 30, 40, 50];
for (let i = 0; i < numbers.length; i++) {
  console.log(`Индекс ${i}: ${numbers[i]}`);
}
```

### for...of (современный способ)

```typescript
const numbers = [10, 20, 30];
for (const num of numbers) {
  console.log(num);
}
// Выведет: 10, 20, 30
```

**Когда использовать:**
- Когда нужен только элемент, а не индекс
- Более читаемо, чем классический `for`

### for...in (для объектов)

```typescript
const person = { name: "Денис", age: 46, city: "Москва" };
for (const key in person) {
  console.log(`${key}: ${person[key as keyof typeof person]}`);
}
```

**Когда использовать:**
- Для обхода ключей объекта
- ⚠️ Не использовать для массивов (обходит строковые индексы)

## 4. Цикл `do-while`

### Синтаксис

```typescript
do {
  // тело цикла
} while (условие);
```

### Как работает

1. Выполняется тело цикла
2. Проверяется условие
3. Если `true` — возвращаемся к шагу 1
4. Если `false` — выходим из цикла

### Ключевое отличие

Тело цикла **выполняется хотя бы один раз**, даже если условие сразу false.

### Пример

```typescript
let input: string;
do {
  input = prompt("Введите 'yes' или 'no':");
} while (input !== "yes" && input !== "no");
```

### Когда использовать

- Когда нужно **гарантировать** хотя бы одно выполнение тела
- Для меню, запросов ввода, валидации

## 5. `break` и `continue`

### `break` — немедленный выход из цикла

```typescript
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break;  // Выход из цикла, когда i === 5
  }
  console.log(i);
}
// Выведет: 0, 1, 2, 3, 4
```

### `continue` — переход к следующей итерации

```typescript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue;  // Пропустить чётные числа
  }
  console.log(i);
}
// Выведет: 1, 3, 5, 7, 9
```

### Когда использовать

- `break`: когда нашёл то, что искал, или произошла ошибка
- `continue`: когда нужно пропустить некоторые итерации

### ⚠️ Осторожно с `break` и `continue`

Они **усложняют понимание** потока выполнения. Часто можно переписать код без них, сделав его понятнее.

**Плохо:**
```typescript
for (let i = 0; i < 100; i++) {
  if (i % 3 === 0) continue;
  if (i > 50) break;
  // Сложная логика
}
```

**Хорошо:**
```typescript
for (let i = 0; i <= 50; i++) {
  if (i % 3 !== 0) {
    // Логика
  }
}
```

## 6. Инвариант цикла — КРИТИЧЕСКАЯ КОНЦЕПЦИЯ

Это **самая важная тема** этой части. Инварианты циклов — основа для **доказательства корректности программ**.

### Что такое инвариант цикла?

**Инвариант цикла** — это условие, которое:
1. **Истинно перед первой итерацией** (перед входом в цикл)
2. **Остаётся истинным после каждой итерации** (если было истинно перед итерацией, то останется истинным и после)
3. **Вместе с условием выхода из цикла** гарантирует корректность результата

### Формальное определение

Для цикла `while (B) { S }`:
- **I** — инвариант цикла
- **B** — условие продолжения

Должны выполняться:
1. **Инициализация**: перед первой итерацией `I` истинно
2. **Сохранение**: если `I` истинно и `B` истинно, то после выполнения `S` инвариант `I` остаётся истинным
3. **Терминация и корректность**: когда цикл завершается (`B` ложно), из `I` и `¬B` следует корректность результата

### Простой пример

```typescript
// Вычисление суммы чисел от 1 до n
function sum(n: number): number {
  let sum = 0;
  let i = 1;
  while (i <= n) {
    sum = sum + i;
    i = i + 1;
  }
  return sum;
}
```

**Инвариант цикла:**
```
sum = 1 + 2 + ... + (i-1)  И  i >= 1
```

**Проверка трёх свойств:**

1. **Инициализация**: перед первой итерацией `sum = 0`, `i = 1`.
   - `sum = 1 + 2 + ... + (i-1) = 1 + 2 + ... + 0 = 0` ✅
   - `i >= 1` → `1 >= 1` ✅

2. **Сохранение**: предположим, инвариант истинно перед итерацией.
   - Было: `sum = 1 + 2 + ... + (i-1)`
   - После `sum = sum + i`: `sum = 1 + 2 + ... + (i-1) + i = 1 + 2 + ... + i`
   - После `i = i + 1`: новый `i' = i + 1`
   - Получаем: `sum = 1 + 2 + ... + (i'-1)` ✅ (инвариант сохранился)

3. **Корректность**: когда цикл завершается, `i > n`.
   - Из инварианта: `sum = 1 + 2 + ... + (i-1)`
   - Из условия выхода: `i = n + 1` (так как `i > n` и `i` увеличивается на 1)
   - Подставляем: `sum = 1 + 2 + ... + n` ✅ (это и есть результат!)

### Почему это важно

Без инварианта ты **не можешь доказать**, что цикл работает правильно. Ты можешь протестировать его на 100 примерах, но это не гарантия.

С инвариантом ты **доказываешь**, что цикл работает для **любых** входных данных.

Это основа **Hoare Logic** (Этап 8) — формальной системы для доказательства корректности программ.

### Ещё один пример: бинарный поиск

```typescript
function binarySearch(arr: number[], target: number): number {
  let left = 0;
  let right = arr.length - 1;
  
  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  
  return -1;  // Не найдено
}
```

**Инвариант цикла:**
```
Если target есть в arr, то он находится в arr[left..right]
```

**Проверка:**
1. **Инициализация**: `left = 0`, `right = arr.length - 1`. Весь массив — `arr[0..arr.length-1]`. ✅
2. **Сохранение**: 
   - Если `arr[mid] < target`, то `target` не может быть в `arr[left..mid]`, значит в `arr[mid+1..right]` ✅
   - Если `arr[mid] > target`, то `target` не может быть в `arr[mid..right]`, значит в `arr[left..mid-1]` ✅
3. **Корректность**: когда `left > right`, диапазон пуст. Если инвариант истинен, `target` не в массиве. Возвращаем `-1`. ✅

## 7. Терминация (завершаемость) цикла

Цикл должен **когда-нибудь завершиться**. Если нет — это **бесконечный цикл**.

### Пример бесконечного цикла

```typescript
let i = 0;
while (i < 10) {
  console.log(i);
  // Забыли i++ — бесконечный цикл!
}
```

### Как доказать терминацию

Нужно найти **вариант** (variant) — величину, которая:
1. Всегда неотрицательна
2. Уменьшается на каждой итерации

**Пример:**
```typescript
let i = 0;
while (i < 10) {
  i++;
}
```

**Вариант:** `10 - i`
- Неотрицателен: пока `i < 10`, `10 - i > 0`
- Уменьшается: на каждой итерации `i` увеличивается на 1, значит `10 - i` уменьшается на 1
- Когда `10 - i = 0`, цикл завершается

### Связь с инвариантом

Для доказательства корректности цикла нужно:
1. **Инвариант** — что сохраняется
2. **Вариант** — что уменьшается (гарантия завершения)
3. **Постусловие** — что истинно после цикла

Это основа **Hoare triples**: `{P} S {Q}` — если перед выполнением `S` истинно `P`, то после истинно `Q`.

## 8. Off-by-one ошибки

Самая частая ошибка в циклах — **ошибка на единицу** (off-by-one).

### Пример 1: неправильная граница

```typescript
// ❌ Плохо
const arr = [1, 2, 3, 4, 5];
for (let i = 0; i <= arr.length; i++) {  // Ошибка: i до 5 включительно
  console.log(arr[i]);  // arr[5] — undefined!
}

// ✅ Хорошо
for (let i = 0; i < arr.length; i++) {  // i от 0 до 4
  console.log(arr[i]);
}
```

### Пример 2: неправильный диапазон

```typescript
// Нужно вывести числа от 1 до 10

// ❌ Плохо
for (let i = 1; i < 10; i++) {  // Выведет 1..9
  console.log(i);
}

// ✅ Хорошо
for (let i = 1; i <= 10; i++) {  // Выведет 1..10
  console.log(i);
}
```

### Как избежать

- Всегда проверяй границы: `<` или `<=`?
- Используй инварианты цикла — они помогают отследить, какие значения принимает переменная
- Пиши тесты для граничных случаев (пустой массив, один элемент, все элементы)

## 9. Вложенные циклы

Циклы могут быть вложенными. Важно понимать, как они работают.

### Пример: таблица умножения

```typescript
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(`${i} * ${j} = ${i * j}`);
  }
}
```

**Сложность:** O(n²) — если внешний цикл выполняется n раз, а внутренний m раз, общее количество итераций — n × m.

### Инварианты вложенных циклов

Каждый цикл имеет свой инвариант. Инвариант внутреннего цикла может зависеть от переменных внешнего.

```typescript
// Сортировка пузырьком
for (let i = 0; i < arr.length - 1; i++) {
  // Инвариант внешнего цикла:
  // arr[n-1-i..n-1] отсортирован и содержит i наибольших элементов
  
  for (let j = 0; j < arr.length - 1 - i; j++) {
    // Инвариант внутреннего цикла:
    // arr[j] — максимум среди arr[0..j]
    
    if (arr[j] > arr[j + 1]) {
      [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
    }
  }
}
```

## 10. Типичные ошибки

### Ошибка 1: Бесконечный цикл

```typescript
// ❌ Плохо
let i = 0;
while (i < 10) {
  console.log(i);
  // Забыли i++
}

// ✅ Хорошо
let i = 0;
while (i < 10) {
  console.log(i);
  i++;
}
```

### Ошибка 2: Off-by-one

```typescript
// ❌ Плохо
for (let i = 0; i <= arr.length; i++) {
  console.log(arr[i]);  // arr[arr.length] — undefined
}

// ✅ Хорошо
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
```

### Ошибка 3: Изменение коллекции во время итерации

```typescript
// ❌ Плохо
const arr = [1, 2, 3, 4, 5];
for (let i = 0; i < arr.length; i++) {
  if (arr[i] % 2 === 0) {
    arr.splice(i, 1);  // Изменяем массив во время итерации!
    // Индексы сдвигаются, пропускаем элементы
  }
}

// ✅ Хорошо
const filtered = arr.filter(x => x % 2 !== 0);
```

### Ошибка 4: Использование `var` в цикле

```typescript
// ❌ Плохо
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// Выведет: 3, 3, 3 (не 0, 1, 2!)
// var имеет function scope, все замыкания ссылаются на одну переменную

// ✅ Хорошо
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// Выведет: 0, 1, 2
// let имеет block scope, каждое замыкание имеет свою копию i
```

### Задание 3 (продвинутое): Функция `gcd`

Напиши функцию `gcd(a: number, b: number): number`, которая возвращает наибольший общий делитель (НОД) чисел `a` и `b` по **алгоритму Евклида**.

**Алгоритм Евклида:**
```
while b != 0:
  temp = b
  b = a % b
  a = temp
return a
```

**Примеры:**
```typescript

gcd(17, 13);   // 1
gcd(100, 25);  // 25
gcd(0, 5);     // 5
```
